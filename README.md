## 📖 Proje Hakkında / About
**TR:** Mehrinaz, estetik ön planda tutularak hazırlanan, özel bir tema ve akıcı bir kullanıcı deneyimi sunan kişisel/özel bir web tasarımıdır. 

**EN:** Mehrinaz is a personal/special web design featuring a custom theme and smooth user experience, created with a strong focus on aesthetics.

---

## ✨ Özellikler / Key Features
- 🌸 **Zarif Konsept Tasarımı / Elegant Concept Design:** Göz yormayan, estetik ve uyumlu renk paleti. / Eye-friendly, aesthetic, and harmonious color palette.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil ve masaüstü ekranlarda kusursuz uyum. / Seamless compatibility on mobile and desktop screens.
- ✨ **Dinamik Etkileşimler / Dynamic Interactions:** Kullanıcı deneyimini artıran akıcı arayüz öğeleri. / Smooth interface elements enhancing user experience.

## 🛠️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik yapı / Semantic structure
* **CSS3:** Stil yönetimi ve özel tasarımlar / Styling and custom designs
* **JavaScript:** Sayfa içi dinamik özellikler / In-page dynamic features
